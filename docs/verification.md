# 検証

## 初期診断（2026-09-11）

WindowsのUSBシリアルポートからESP32-D0WD-V3 / 4MBフラッシュを確認。
SDA=21 / SCL=22 / 3.3Vの配線でI2Cアドレス0x68が応答、WHO_AM_I=0x70。
MPU6500相当として初期化し、加速度・ジャイロを14回連続で取得。基板印刷だけでは実装型番を断定しない。

## リアルタイム版

- ESP32 core 3.3.11でリアルタイム版と診断版のビルド成功。
- Windows Python 3.13で6テスト成功（不正パケット、識別値、途絶、GUIエラー表示と復旧）。
- COM3実機GUIで132サンプル連続取得、エラー0、WHO_AM_I=0x70、加速度合計1.020g、約15.9Hz。
- 波形の描画、切断時の数値消去・ポート解放を確認。
- 初回GitHub CIのPython checksとFirmware build成功。
- 実機USB抜き差し・配線を動かす試験は未実施。模擬イベントでGUIのエラー/復旧を検証。
- Windows専用環境への配置とデスクトップの起動ショートカット作成済み。

数値精度・校正・長時間の振動耐性は検証対象外。通信成功ははんだ品質全体を保証しない。
